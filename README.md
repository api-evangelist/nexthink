Nexthink is a digital employee experience (DEX) management company. Its Infinity platform combines real-time endpoint analytics, employee sentiment, and automated remediation so IT teams can proactively detect and fix issues across every device. Nexthink exposes a set of OAuth 2.0-secured public APIs — NQL (query), Remote Actions, Workflows, Enrichment, Campaigns, Data Management, and Spark — that let external tools pull DEX data and drive endpoint automation. Backed by Index Ventures; added to the API Evangelist network and enriched from Nexthink's published developer documentation.

**Areas:** Company · Business Applications · Digital Employee Experience · Endpoint Analytics · IT Operations · Automation · Observability

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Nexthink: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
